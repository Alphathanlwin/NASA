# Archived: Garvesty prototype (not built, not deployed)

This folder is a copy of the Garvesty implementation as it stood on `main` at
commit `8fa3376` (14 Nov 2026), taken when the FieldShift build was merged back in
as the submitted app. Paths inside mirror the repository root at that commit.

It includes the team's later Garvesty work: the input-shock rule (fertilizer /
pesticide / cash), time-context cards, IoT sensor notes (`iot_sensor.md`),
`data/DATA_USAGE.md`, the model evaluation report and a UI reference screenshot
(`image/image.png`, a third-party product shown for design inspiration only).

Nothing here is installed, imported, tested or deployed. The active application is
FieldShift, described in `docs/FieldShift_Digital_Twin_Project.md`. Build artefacts
that were tracked on that branch (`.venv`, `node_modules`, `dist`, pnpm store,
`__pycache__`, `.pytest_cache`) are not copied and are ignored by `.gitignore`.
