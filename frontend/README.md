# Field Shift - frontend

React 19 + TypeScript + Vite. The app, data, and how to run and test it are described in the
[project README](../README.md).

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # static build in dist/, served at /NASA/
npx vitest run src # unit tests (run from a path with an upper-case drive letter on Windows)
```
